# Sistema Padaria Pão Quente

## Sobre o projeto

Este projeto foi desenvolvido em Java para a disciplina de Algoritmos e Programação do IBMR.

Criamos um sistema para ajudar no controle de estoque e vendas de uma padaria. Com ele, é possível cadastrar produtos, registrar vendas, atualizar preços e acompanhar o faturamento.

Também desenvolvemos uma interface gráfica utilizando Java Swing, para facilitar a visualização das informações e o uso do sistema.

## Funcionalidades

- Cadastro de produtos
- Consulta e reposição de estoque
- Registro de vendas
- Alteração de preços
- Busca de produtos pelo nome
- Aviso de estoque baixo
- Cálculo do faturamento semanal e mensal
- Gráficos de vendas e faturamento
- Relatórios e histórico de operações

## Tecnologias utilizadas

- **Java:** desenvolvimento do sistema
- **Java Swing:** criação da interface gráfica
- **Eclipse:** ambiente utilizado para trabalhar com os códigos
- **ArrayList:** armazenamento dos produtos
- **Matrizes e vetores:** registro de vendas e cálculos
- **GitHub:** armazenamento e organização do projeto

## Organização das classes

Dividimos o projeto em cinco classes:

- `Produto.java`: guarda as informações dos produtos.
- `Padaria.java`: controla o estoque, as vendas e os cálculos.
- `Aplicacao.java`: apresenta o menu do sistema.
- `Relatorio.java`: mostra os relatórios e resultados.
- `TelaGrafica.java`: contém a interface gráfica do sistema.

## Interface gráfica

Escolhemos a cor roxa para a interface e azul para os gráficos. A ideia foi deixar o sistema organizado, com as principais informações fáceis de encontrar.
